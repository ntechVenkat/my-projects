Developed the Project through REDUX, CRUD operations through REDUX state management library
Place all these files into any own folder of src in our React Project,
Then Place the our main project file ReduxAPI.js into App.js of the our React project which is located in src folder.
To show the results of our project, Please run our dummy data base using the command if you have already installed json-server, like **npm i json-server -g**
Then give the command **npx json-server --watch db.json --port 3200**
